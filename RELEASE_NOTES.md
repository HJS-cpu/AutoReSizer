## AutoReSizer - Window Size/Position Manager

Automatisches Fenster-Management-Tool fuer Windows (AutoHotkey v2.0).

### Features
- **Automatische Fensterpositionierung:** Regeln fuer Fenster definieren, die automatisch angewendet werden
- **Flexibles Matching:** Fenster per Titel oder Klasse erkennen
- **Maximieren:** Fenster automatisch maximieren statt fixe Groesse
- **Hotkey-Unterstuetzung:** Konfigurierbarer Hotkey zum schnellen Erfassen von Fenstern
- **Mehrsprachig:** Deutsch und Englisch (erweiterbar)
- **Autostart:** Optional mit Windows starten
- **Stay on Top:** `Strg+Win+Space` schaltet "Immer im Vordergrund" um (Hidden Feature)

### Installation
1. ZIP herunterladen und entpacken
2. `AutoReSizer.exe` starten
3. Regeln ueber das Tray-Menue erstellen
