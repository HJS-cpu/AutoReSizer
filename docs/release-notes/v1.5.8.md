### Changes in v1.5.8
**New features**
- **Stay on Top:** Press `Ctrl+Win+Space` to toggle "Always on Top" for the active window, confirmed by a splash notification (hidden feature)

**UI improvements**
- Dialog windows now display icons matching their tray menu entries
- Tray icon (active state) now uses the application icon
- Cleaner tray tooltip (removed hotkey hint)

### Installation
1. Download and extract the ZIP file
2. Run `AutoReSizer.exe`
3. Create rules via the tray menu
