### Changes in v1.5.4
**Bug fixes**
- Fixed the rules list not refreshing when a rule is added via the hotkey capture dialog while the Rules Manager window is already open
- Improved window-state synchronization so the displayed rules are always current

### Installation
1. Download and extract the ZIP file
2. Run `AutoReSizer.exe`
3. Create rules via the tray menu
