### Changes in v1.6.1
**Bug fixes**
- Rules are no longer applied in the background while the rules manager is open
- Hotkey capture now requires a modifier key (except F1–F12) — plain keys like a letter or Space can no longer be hijacked system-wide
- Fixed a possible error dialog when closing the settings window during a running hotkey capture
- Rule matches/names with special characters (e.g. •, →, emoji) no longer break silently: the INI file is now stored as UTF-16
- Windows that reuse a recycled window handle are no longer skipped
- "Apply rules now" applied multiple matching rules to the same window and counted it twice
- Double-clicking an empty list area no longer opens the previously focused entry; capturing a window without a title no longer creates a dead rule
- Opening the language selection while .lng files are missing no longer closes the application
- Tray notifications showed title and text swapped

**Robustness & usability**
- AutoReSizer's own dialogs are excluded from rule matching
- A missing AutoReSizer.dll no longer causes error cascades; the autostart registry entry now quotes the executable path
- Hover tooltips hide automatically after 3 seconds; the first run shows English texts until a language is chosen

**Performance**
- No background window scan while no rules are active; active-window polling only runs while the capture hotkey is enabled

**Internal**
- Additional localized strings; About dialog labels localized

### Installation
1. Download and extract the ZIP file
2. Run `AutoReSizer.exe`
3. Create rules via the tray menu
